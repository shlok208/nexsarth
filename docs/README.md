# Lead Management + Automated Follow-up System

This is a complete Lead Management System with automated email follow-ups, powered by Supabase.

## Features
- Complete CRUD for Leads
- Automated Follow-up Emails (using SMTP)
- Inbound Message Sentiment Analysis
- Supabase (hosted PostgreSQL) for reliable cloud persistence
- Next.js + Tailwind CSS Client (Pages Router)
- Dedicated Python Automation Worker

## Setup Instructions
Please refer to [Setup Guide](setup.md) for detailed instructions on running all services.

## Technologies Used
- Backend: FastAPI, SQLAlchemy, Pydantic
- Frontend: Next.js, React, TailwindCSS, TypeScript
- Automation: Python, Schedule Loop
- Database: Supabase (PostgreSQL)
